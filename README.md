# 信号与系统 · 学习台

依据《信号与系统（修订版）》（曾喆昭 主编）目录整理的单页学习应用。

## 打开方式

在 Microsoft Edge 中打开：直接双击 **`打开学习台.cmd`**。启动器会自动查找 Edge 安装位置，并用新窗口打开学习台。

也可以直接双击 `index.html`，或把该文件拖入 Edge 窗口。所有内容、样式与脚本均为本地文件，不依赖网络。

如果浏览器对本地 `file://` 页面的存储或 PDF 跳转限制较多，可在当前目录运行：

```powershell
./start.ps1
```

脚本会在本机 `127.0.0.1:8765` 启动一个静态服务器并打开浏览器，不向外部网络暴露服务。

## 已实现

- 8 个独立章节板块，148 个独立小节板块，含每章习题与复盘。
- 总进度、章节进度、小节进度三级联动；小节支持“未开始 / 已阅读 / 已掌握”三态。
- 每章一张 SVG 知识思维导图，点击节点可跳转到对应小节，支持缩放与全屏。
- 全局知识检索，支持章节号、标题、概念、公式和关键词。
- 229 张公式速查卡，支持章节筛选、关键词搜索、一键复制和随机抽背。
- 每小节独立笔记、书签、自检问题和教材页码直达。
- 深浅色主题、学习数据导入/导出、移动端适配。
- 公式速查卡已上线；章节自测、错题本、学习打卡继续保留扩展入口。

## 数据说明

学习进度、书签和笔记保存在浏览器本机 `localStorage` 中，不会上传。教材 PDF 已随项目复制为 `assets/book.pdf`，小节页码按原书印刷页码映射到 PDF 页。

知识卡片为学习辅助摘要，用于建立结构、复习公式和定位易错点；完整推导、例题与习题答案请查阅随附教材。
